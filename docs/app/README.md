# Citrons Android APK (sideload)

- File: [citrons-android.apk](./citrons-android.apk)
- Direct link (site): https://citrons.lat/app/citrons-android.apk

Install: download on an Android phone → open the file → allow install from this source.

This build is a WebView shell around https://citrons.lat (same online games as the website).

Long-press in the app → **Refresh game** to pull the latest web version.
